Behind the radar

Find the signal before you create.

NicheRadar turns recent public YouTube Shorts metadata into a clear research snapshot: what is gaining traction, which creators are outperforming their size, and how much evidence supports the current signal.

The project

Research a niche before you commit to it.

It helps creators move beyond a vague hunch by combining a reviewable search plan, recent public YouTube data and transparent, deterministic scoring in one ranked report.

01

Start with a clean search

A likely spelling issue can be suggested before expansion, but NicheRadar never silently changes the niche a user entered.

02

Review the search plan

An AI service proposes focused YouTube search angles. The user can edit, remove or add queries before any YouTube analysis starts.

03

Compare current performance

Recent public views, upload age and channel size become comparable measures such as Views/day and Subscriber multiplier.

Method

How an analysis is built

AI helps prepare and explain the research, while the video collection, ranking and scores remain deterministic.

  1. 01

    Check the niche

    An optional, high-confidence spelling suggestion is shown first. Keeping the original niche always remains a choice.

  2. 02

    Expand and review

    Groq generates up to ten concise search queries; the original niche stays locked as the first query.

  3. 03

    Collect and rank

    NicheRadar searches recent public YouTube data, removes duplicates, keeps Short candidates and calculates each metric from the returned metadata.

  4. 04

    Explain the result

    After the dashboard is ready, an optional Groq summary turns completed statistics into three observations. It never reruns YouTube collection.

The signals

How to read a report

These labels make the scoring model inspectable rather than treating the dashboard as a black box.

Breakout

A smaller or growth-stage channel whose video clears the view-to-subscriber threshold set for its channel-size band.

Exceptional

A larger channel with a video that has more than 40 views per subscriber, indicating unusually strong reach for its size.

Virality Score

A deterministic 0–100 score for current activity, using breakouts, median Views/day, exceptional highlights and channel diversity.

Confidence Score

A deterministic 0–100 measure of evidence strength from query breadth, candidate and result counts, and subscriber data coverage.

Report controls

Inspect the same results your way

  • Up to 50 ranked Short candidates from the completed analysis
  • Client-side ranking by Views/day, Total views or Subscriber multiplier
  • Breakout and exceptional-performance highlights
  • Three optional AI observations and a deterministic New-Creator Signal

Data and limitations

A useful snapshot, with clear boundaries

  • Uses public metadata supplied through the YouTube Data API.
  • Does not analyse video frames, audio, transcripts, watch time or retention.
  • Results are time-bound, query-dependent and affected by available API data and quota.
  • Missing subscriber data can make a multiplier unavailable.

Scope

Research support, not a guarantee of success.

NicheRadar uses public YouTube data and Groq for spelling suggestions, query expansion and optional summaries. It is an independent portfolio project, not affiliated with or endorsed by YouTube, Google or Groq. Its live-analysis environment is privately staged; its scores and summaries support research and do not guarantee growth, virality, income or future performance.
